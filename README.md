# 🚀 AI Career Intelligence Agent

## Overview

AI Career Intelligence Agent is an intelligent career guidance platform developed using Python and Streamlit. The system analyzes resumes against job descriptions, calculates ATS compatibility scores, identifies skill gaps, recommends suitable career paths, generates personalized learning roadmaps, and provides downloadable career reports.

The goal of this project is to help students, graduates, and job seekers improve their resumes and increase their chances of securing internships and employment opportunities.

---

## ✨ Features

### 📄 Resume Analysis

* Upload PDF resumes
* Automatic resume text extraction
* Skill extraction and classification

### 🎯 ATS Match Score

* Compare resumes against job descriptions
* Calculate ATS compatibility percentage
* Evaluate resume-job alignment

### 🔍 Skill Gap Analysis

* Detect missing skills
* Identify job requirements not covered in the resume
* Highlight improvement areas

### 📚 Learning Roadmap

* Generate personalized learning recommendations
* Suggest skills and technologies to learn
* Support career development planning

### 💪 Strengths & Weaknesses Analysis

* Identify resume strengths
* Highlight weaknesses based on target roles
* Provide actionable feedback

### 🎯 Career Role Recommendation Engine

* Recommend suitable career paths
* Match resumes against multiple technology roles
* Display career-role compatibility scores

### 📊 Visual Analytics Dashboard

* ATS score visualization
* Skill match analysis charts
* Career role comparison charts

### 📄 PDF Career Report

* Download complete analysis report
* Includes ATS score, strengths, weaknesses, skill gaps, and recommendations

### 🤖 AI Resume Feedback (Experimental)

* Gemini AI integration (currently under development)
* AI-powered resume review and career guidance
* Future enhancement for advanced personalized feedback

## ⚙️ System Workflow

1. Upload Resume (PDF)
2. Extract Resume Content
3. Extract Resume Skills
4. Paste Job Description
5. Extract Job Description Skills
6. Calculate ATS Match Score
7. Identify Missing Skills
8. Generate Learning Recommendations
9. Analyze Strengths & Weaknesses
10. Recommend Suitable Career Roles
11. Generate PDF Career Report
12. Visualize Results with Interactive Charts
