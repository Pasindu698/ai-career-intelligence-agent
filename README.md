# AI Career Intelligence Agent

An AI-powered career analysis tool that evaluates resumes against job descriptions and provides ATS match scores, skill gap analysis, and career recommendations.

## Features

* Resume PDF Upload
* Job Description Analysis
* ATS Match Score Calculation
* Skill Extraction
* Missing Skills Detection
* Streamlit Web Interface

## Tech Stack

* Python
* Streamlit
* PyPDF
* Scikit-learn
* Pandas

## Future Enhancements

* Learning Roadmap Generation
* AI Resume Feedback
* PDF Report Generation
* LLM & RAG Integration
